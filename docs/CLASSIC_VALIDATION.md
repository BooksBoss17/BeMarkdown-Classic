# Classic 发行验证

当前版本：v0.3.0-classic.2；日期：2026-11-14。初始 classic.1 已标记预发行，因安装 RECORD 的路径/安装器差异不能用于新机器部署。

## 完整范围

以正式安装 0.3.0+sm120.2 为基线，保留全部 236 个 Python 模块，234 个逐字节相同。doctor.py 对齐正式诊断 token 预算；stage_forecasts.py 增加冻结安装载荷 RECORD 等价规则。转换判定算法、模型、推理参数和资源预算不变。完整图片筛选引擎另补充 Windows CreateProcess 失败前的有界恢复，源码与 engine.zip 对应。

13 个必要模型共 14,700,742,038 字节，含 11 个转换模型和 B200/Qwen 筛选模型。固定上游 revision、实际下载路径、B200 分片附件哈希及许可证均已核对。本机模型载荷逐文件 SHA256 通过。新视觉串行候选未包含。

## 实际验证

- Windows x64 / RTX 5070 Ti SM120；固定 Python、Paddle CUDA 12.9 和隔离 Qwen 环境。
- 71 项本地回归通过，覆盖安装器、下载、源码/归档一致性、资源指纹、图像归属和筛选接口。
- 官方 MCP SDK auto / legacy 两种启动模式通过，12 个工具及视觉门控通过。
- 合成自有 DOCX、IMAGE、扫描 PDF 在初始发行候选中完成完整受管转换。IMAGE/PDF 均完成 B200＋Qwen 筛选，各留 7 项待审；DOCX 为 CLEAN。
- 修订版重新执行 IMAGE：OCR 完成，首次筛图进程在创建前遇到 WinError32，尚无模型请求或存活子进程。修复后通过受管 --screen-existing 复用已完成 OCR，只恢复筛图阶段，最终 COMPLETE、工作进程退出确认。该次记录是含恢复的完整流程，不冒充一次冷运行。
- 独立新环境用 pip 实际安装全部 12 个冻结核心依赖：Paddle 档案 5 项、Qwen 档案 7 项。METADATA、严格载荷 RECORD 等价摘要与关键加载器/原生二进制均匹配。相关差异和拒绝测试见[安装指纹说明](PORTABLE_INSTALLATION.md)。
- 新核心依赖的 Ovis/Xiaomi GPU 检查通过；Paddle 测试环境补齐复用的 CUDA 运行库后，9 模型 GPU 检查通过。已通过的 Qwen 请求没有重复执行。其他传递依赖与模型复用，因此这仍不是完整新机器冷安装认证。

## 验证边界

源码、对应 wheel、完整安装入口、模型下载与所有处理分支均交付。完整系统安装涉及 LibreOffice 和 VC++ 的管理员确认，本次没有完成从零系统安装；截图 DOCX/LibreOffice 分支未新增实测。公开安装器不把失败子项或不匹配运行身份当作安装完成。

小型转换、GPU 自检和接口检查不是整本教材准确率、零误删或任意输入资源认证。文字转写、公式分歧、阅读顺序和图片待审须由具备视觉能力的宿主处理。当前固定档案只认证上述设备，其他硬件需独立验证。
