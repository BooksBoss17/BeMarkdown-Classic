# 安装指纹的可移植性

v0.3.0-classic.1 发现同版本依赖由 pip/uv 安装到不同目录时，RECORD 中的控制台启动器和安装元数据会变化，导致旧整文件哈希拒绝新环境。初始版本已标记为预发行，历史测试仍保留。

修订版保留原始 RECORD 哈希作为观察证据，并增加由已验证依赖生成的冻结载荷清单摘要。只有冻结的 Windows console launcher 文件、该发行包的 INSTALLER/REQUESTED/direct_url/uv_cache/RECORD 和生成的 __pycache__ 字节码行可不参与载荷等价摘要。所有其他路径、大小和哈希必须逐项等价；未登记脚本不可排除。METADATA 原始 SHA256、实际关键加载器/原生二进制 SHA256、Python 可执行身份和全部模型权重/源码/预算规则继续严格核验。重复载荷记录、载荷变更、未知规则与加载器篡改均拒绝。

这是安装表示的有限等价规则，不是允许任意同版本包或替换模型。安装器仍会在不匹配时失败，未认证的环境不能通过写入自己的新哈希获得认可。

实际新安装验证覆盖两套 Python 环境中的 12 个核心依赖，包含官方 Paddle CUDA 12.9 和 PyTorch CUDA 13.0 wheel。安装器元数据差异未掩盖任何模型载荷变化；完整系统冷安装边界见 CLASSIC_VALIDATION.md。
